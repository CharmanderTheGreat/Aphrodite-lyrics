# 🏎️ Ayen #01 // Birthday Grand Prix 2026

An exclusive, interactive Formula 1-themed birthday showcase and arcade simulator portal created as a dedicated birthday gift for my friend, **Ayen**. 

Built completely from scratch using pure HTML5, modern responsive CSS, Canvas API, and client-side payload encryption.

---

## 🎂 Project Purpose & Concept

This project serves as an interactive digital birthday gift and celebration portal. Designed to reflect Ayen's passion for Grand Prix racing, it transforms traditional birthday greetings into an authentic paddock telemetry experience:

- **Encrypted Birthday Vault**: All personal messages, photos, and tribute cards are protected under a secure access gate that only reveals content with the birthday celebrant's secret clearance PIN code.
- **Circuit Tribute Gallery**: An iconic Grand Prix calendar featuring special friendship milestones and dedication cards styled as real Formula 1 race rounds.
- **Custom Birthday Grand Prix Game**: An embedded arcade simulator challenge where the driver navigates traffic on track to set high scores and celebrate the occasion.

---

## 🏁 Key Features

- **Paddock Security Gate**: Telemetry-style passcode clearance screen with automated focus traversal and brute-force prevention.
- **Encrypted Single-File Bundle**: All images and personal birthday messages are obfuscated and stored in memory, keeping raw personal files hidden from the public repository.
- **Responsive Telemetry Showcase**: Horizontal swipeable circuit cards with smooth scroll-snapping for both mobile and desktop screens.
- **Interactive 2D Racing Simulator**: Built-in 60 FPS top-down HTML5 canvas game featuring procedural rival spawns, dynamic lane scaling, and dual keyboard/mobile touch controls.
